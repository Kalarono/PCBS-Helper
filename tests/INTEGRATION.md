# Проверка интеграции — 7 октября 2026

## Обновление 1.2.0

- Сборка и 13 проверок CPU matcher прошли.
- В игре загружается PCBS Helper 1.2.0; отдельный Cheat Mod больше не загружается.
  Его DLL сохранена вне plugins, настройки четырёх оставленных функций импортированы.
- F1 открывает Tweaker в общей тёмной теме. В нём ровно четыре функции:
  Install All Apps, Instant 3DMark, Show Diagnose Objectives, Show Hidden Objectives.
- Переключение Install All Apps проверено в интерфейсе и по фактическому значению
  DebugVars в логе; исходное состояние восстановлено.
- Реализованы компактный F2, полное окно и переключение Expand/Compact без
  повторной загрузки HTML. Калькулятор получил адаптивную тёмную тему.
- По просьбе пользователя управление игрой остановлено. Визуальная проверка
  размеров F2, сохранения полей при переключении и совместного отображения с F3
  оставлена для ручной проверки пользователем.

## Проверка 1.1.0

Версия: PCBS Helper 1.1.0; PC Building Simulator 1.15.3; BepInEx 5.4.23.5.

Проверено в обычной карьере:

- Панель автоматически появилась при открытии письма с CanPlay-целью.
- Feudal Fantasy XIII, рекомендуемые требования: 16 ГБ ОЗУ, 4 ГБ VRAM,
  AMD Radeon RX570, AMD Ryzen 7 Eight Core 1700, 40 ГБ диска.
  Значения совпали с Will it Run?. Сокет исходного CPU — AM4.
- Закрытие письма скрывает панель; повторное открытие показывает её снова.
- F3 закрепляет панель; выход из виртуального монитора оставляет её видимой;
  повторное F3 скрывает её.
- Ручной поиск фильтрует список игр, выбор профиля обновляет требования.
- На 13-м уровне закрытые Intel не показаны; выводится сообщение об отсутствии
  подходящих открытых аналогов.
- F2 по-прежнему загружает локальный HTML-калькулятор с меню совместимости;
  повторное F2 возвращает управление игре.
- Загруженная DLL совпадает с собранным пакетом по SHA-256.

Автоматические проверки CPU matcher: **13 утверждений прошли**. Проверены оба
направления Intel/AMD, точное равенство порогу, запрет более слабых CPU, сортировка
по оценке/цене, дубликаты, некорректные оценки, исключение закрытых деталей и
отсутствие запасного списка закрытых моделей в обычной карьере.

В коде фильтр по уровню включается только для `GameMode.CAREER`. Для Esports DLC,
IT Expansion и свободной сборки доступность не зависит от уровня. Подключено
чтение профиля цели EsportsInstalledAndPlayableObjective. Эти режимы отдельно
в игровом интерфейсе пока не проверялись; перед публичным релизом нужны проверки
на соответствующих сохранениях.
