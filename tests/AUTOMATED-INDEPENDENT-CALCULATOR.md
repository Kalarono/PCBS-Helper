# Проверка собственного калькулятора, 10 октября 2026

PCBS-Helper 1.0.0, PC Building Simulator 1.15.3, BepInEx 5.4.23.5, Windows x64.

## Источник данных и расчёт

- Каталог прочитан из работающей PCBS: 126 CPU, 316 GPU, 145 плат, 339 корпусов,
  342 модели ОЗУ, 127 накопителей. Данные не включены в DLL или Git.
- `GameScoreOracle.cs` вызвал настоящие игровые `PartDescCPU.Test` и
  `PartDescGPU.Test`: 4738 случаев, включая разные частоты, каналы памяти и
  одну/две GPU. Все совпали с собственным ядром JavaScript.
- Дополнительно прошли 24 проверки подбора, бюджета, марки корпуса,
  недоступной второй GPU, замены CPU вместе с платой и этапа подготовки геометрии.
- Контрольная комбинация i7-7700K / EVGA GTX 1080 / 2133 MHz / один канал
  дала 6495 баллов.

- Браузерные проверки: базовое состояние/восстановление (13 + 11),
  перенос заданий (19), оформление и ограничения (20), корзина (24),
  собственный интерфейс/история/замена деталей (14). Ошибок JavaScript нет.

  MSI GTX 980 Ti GAMING 6G GOLDEN EDITION, RAM 3200 MHz, один канал:
  CPU 4779, GPU 5454, итог 5340. Состояние сохранено.
- Прежние поля и импортированное задание восстановились после перезапуска.
- Геометрия загружена по кадрам, поисковые кнопки разблокированы, локальный
  `game-geometry-cache.json` создан. Калькулятор сообщает о завершении в логе.
- Сопоставление 1264 моделей с игровыми ID прошло без конфликтов.
- Остальные проверки Build.ps1 -Test прошли: F3 CPU matching, позиции окон,

  состояние калькулятора и локализация.

## Исправление сохранённых столбцов апгрейда

- Сохранённые строки прежнего формата восстанавливаются под заголовками
  CPU / количество GPU / охлаждение GPU / GPU / плата / цена / остаток / балл / Вт.
- Промежуточный формат собственного интерфейса с частотой RAM во втором
  столбце распознаётся отдельно; количество GPU переносится на своё место,
  охлаждение восстанавливается из каталога выбранной/установленной GPU.
- Новые состояния содержат имена столбцов, поэтому восстановление не зависит
  от их физического порядка. Несовместимые результаты не выводятся под чужими
  заголовками; поля и история сохраняются.
- 19 проверок состояния прошли. В браузере проверена строка из сообщения
  пользователя (Pentium G4600, 1 + 1, Air, GTX 1070, 640, 860, 6993, 381)
  и новый расчёт апгрейда. Ошибок JavaScript нет.

## Пакеты

- Встроены девять собственных ресурсов; `calculator.html` отсутствует.
- Полный ZIP содержит BepInEx, хелпер, обе TXT-инструкции и лицензию загрузчика.
- DLL-only ZIP содержит DLL и обе TXT-инструкции. Целостность ZIP и равенство
  вложенной DLL релизному файлу проверены.
- Прежний HTML и старые релизные архивы сохранены в `build/backups/`.

Оценки предполагают стабильные частоты без перегрева. Проверка самого
игрового теста на физически собранных новых ПК и совместимости других модов
не заменяется эталонными вычислениями. Сценарии на отдельных сохранениях
Esports/IT Expansion в этой сессии не выполнялись.
