# История версий PCBS-Helper

## 1.2.3 — интерфейс и курсор

- F1 называется PCBS Helper на обоих языках. В F2 используется
  «Помощник по сборке» / Build Helper, в F3 — «Помощник Will it Run?».
- В F1 рядом с функциями указаны клавиши открытия (по умолчанию F2/F3).
- Убраны лишние подписи и подсказки о перетаскивании; окна по-прежнему
  можно перемещать за заголовок.
- Alt включает и выключает курсор нажатием. Закрытие, переключение окна
  и потеря фокуса освобождают курсор и управление игрой.
- По умолчанию подбираются 10 вариантов; количество GPU показано как 1/2.
- Поля обязательных моделей скрыты; импорт задания продолжает применять их.

## 1.2.2 — русский и английский интерфейс

- Язык игры применяется ко всем панелям, вкладкам, полям, кнопкам,
  выпадающим спискам, подсказкам и сообщениям калькулятора.
- Пояснения хелпера в сохранённых заказах переключаются вместе с интерфейсом.
- Переключение языка не меняет модели деталей, значения фильтров,
  комментарии, результаты и сохранения. Для других языков используется английский.

## 1.2.1 — правки и улучшения

- Установка через BepInEx и одну DLL: все файлы калькулятора встроены в хелпер.
- Перемещение окон и сохранение их позиций после перезапуска игры.
- Compact / Expand для калькулятора с сохранением данных.
- Сохранение полей и результатов всех четырёх вкладок между запусками;
  Clear очищает только текущую вкладку.
- Автоматические Career Level и целый % Through; ручной All Parts Unlocked?.
- Переключатели Calculator и Will it Run Helper в Tweaker.
- Взаимное закрытие окон F1/F2/F3 без возврата прежнего окна.
- В Will it Run? отображается один самый дешёвый доступный аналог CPU другой
  марки с сокетом. Ограничение уровня применяется только в обычной карьере.
- Кнопка «Помощник» / Helper в 3DMark-письмах переносит данные заказа в
  Build Maker или Build Upgrader; учитываются поддерживаемые условия заказа.
- Кнопка позиционируется после раскладки письма, без начального скачка.
- Условия по маркам деталей вне поиска Build Upgrader (например, HyperX RAM)
  больше не блокируют подбор CPU/GPU/платы после переноса через «Помощник»;
  они отображаются для отдельной проверки в игре.
