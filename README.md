# PCBS Helper

**Помощник для первой PC Building Simulator. Версия 1.2.1.**

В игре появляются три окна: настройки удобства, калькулятор сборок и системные
требования игр. Всё открывается прямо в игре. После установки отдельную
программу запускать не нужно.

## Что понадобится

- **PC Building Simulator 1 на Windows.** Проверено на версии игры **1.15.3**.
  Для PC Building Simulator 2 этот мод не предназначен.
- **BepInEx 5 для Windows x64** — программа, которая позволяет игре загружать моды.
- **PCBSCalculator.dll** — сам хелпер. Калькулятор и все его файлы уже внутри DLL.

## Как установить

### Шаг 1. Найдите папку игры

1. Закройте игру.
2. В библиотеке Steam нажмите правой кнопкой на **PC Building Simulator**.
3. Через меню **«Управление»** откройте локальные файлы игры.
4. Проверьте, что в открытой папке есть **PCBS.exe** и папка **PCBS_Data**.

Дальше под «папкой игры» имеется в виду именно эта папка.

### Шаг 2. Установите BepInEx

Если у вас уже установлен и работает **BepInEx 5**, переходите к шагу 3.

1. Откройте [официальную страницу BepInEx 5.4.23.5](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5).
2. В разделе **Assets** скачайте **BepInEx_win_x64_5.4.23.5.zip**.
3. Распакуйте содержимое архива прямо в папку игры.
4. Рядом с **PCBS.exe** должны появиться **winhttp.dll**, **doorstop_config.ini**
   и папка **BepInEx**.
5. Запустите игру один раз, дождитесь главного меню и закройте её.
   Внутри BepInEx появятся настройки и файл **LogOutput.log**.

Для этого хелпера выбирайте **BepInEx 5 / win_x64**. Архивы **x86**, **Patcher**,
**Source code** и BepInEx 6 для этой инструкции не подходят.
Подробности установки есть в [официальной инструкции BepInEx](https://docs.bepinex.dev/articles/user_guide/installation/index.html).

### Шаг 3. Установите хелпер

1. На странице проекта откройте **Releases** и скачайте **PCBSCalculator.dll**.
   Если готовый выпуск упакован в ZIP, сначала извлеките из него DLL.
   **Source code** — это исходники для разработчиков, а не готовый мод.
2. В папке игры откройте **BepInEx**, затем **plugins**.
   Если папки plugins ещё нет, создайте её.
3. Внутри plugins создайте папку **PCBSCalculator**.
4. Скопируйте в неё файл **PCBSCalculator.dll**.

Должно получиться так:

```text
PC Building Simulator/
├─ PCBS.exe
├─ PCBS_Data/
├─ winhttp.dll
├─ doorstop_config.ini
└─ BepInEx/
   ├─ core/
   ├─ config/
   └─ plugins/
      └─ PCBSCalculator/
         └─ PCBSCalculator.dll
```

Если раньше стоял отдельный **Cheat Menu**, перенесите его **CheatMod.dll**
из `BepInEx/plugins` в другую папку, например на рабочий стол. Его функции уже
включены в хелпер; две копии меню будут мешать друг другу на F1.

### Шаг 4. Запустите и проверьте

1. Запустите игру обычным способом через Steam.
2. Загрузите сохранение и зайдите в мастерскую.
3. Нажмите **F1** — должно открыться окно **Tweaker**.
4. Нажмите **F2** — должен открыться калькулятор.
5. Нажмите **F3** — должна открыться панель системных требований.

На некоторых клавиатурах понадобится **Fn + F1/F2/F3**.

## Управление: самое необходимое

| Клавиша или действие | Что делает |
| --- | --- |
| **F1** | Открыть или закрыть Tweaker. |
| **F2** | Открыть или скрыть калькулятор. |
| **F3** | Открыть/закрепить требования; повторное нажатие скрывает закреплённую панель. |
| **Esc** | Закрыть Tweaker или скрыть калькулятор. |
| **Удерживать Alt** | Получить курсор для кнопок и полей компактных окон. |
| **Перетащить заголовок окна мышью** | Поставить окно в удобное место. |

Положение каждого окна запоминается даже после перезапуска игры.
При открытии другого окна предыдущее закрывается. Например, после
**F3 → F2 → закрыть F2** окно F3 само не возвращается.

## F1 — Tweaker

Нажмите **F1** и включите нужную галочку. **ON** означает «включено»,
**OFF** — «выключено». Изменения применяются сразу и запоминаются.

| Переключатель | Для чего нужен |
| --- | --- |
| **Install All Apps** | Устанавливает приложения на игровом ПК. После включения откройте на этом ПК приложение установки/удаления программ — **Add/Remove Programs**. |
| **Instant 3DMark** | Убирает ожидание теста 3DMark. Сам тест нужно запустить; результат зависит от комплектующих ПК. |
| **Show Diagnose Objectives** | Показывает цели задания, которые обычно раскрываются после диагностики. |
| **Show Hidden Objectives** | Показывает скрытые условия задания. |
| **Calculator** | Включает/выключает калькулятор, F2 и кнопку «Помощник» в письмах. |
| **Will it Run Helper** | Включает/выключает панель требований, F3 и автоматический показ требований. |

Для выключения функции снимите её галочку. Закрытие самого окна Tweaker
не выключает выбранные функции.

## F2 — калькулятор

Нажмите **F2**. Для ввода в маленьком окне удерживайте **Alt** и нажмите
на нужное поле мышью.

### Какую вкладку выбрать

| Вкладка | Что считать | Кнопка расчёта |
| --- | --- | --- |
| **3DMark Score** | Примерный результат выбранных CPU, GPU и ОЗУ. | **Calculate** |
| **Build Maker** | Новую сборку под нужный результат и бюджет. | **Get Builds** |
| **Build Upgrader** | Апгрейд уже существующего компьютера. | **Get Upgrades** |
| **Part Replacer** | Варианты замены деталей существующего компьютера. | **Get Parts** |
| **History & Saves** | Историю расчётов и сохранённые варианты. | Просмотр записей. |

CPU — процессор, GPU — видеокарта, RAM — оперативная память.

### Кнопки окна

- **Expand** — развернуть калькулятор в большое окно.
- **Compact** — вернуть маленькое окно на сохранённое место.
- **− / +** — уменьшить или увеличить размер текста и элементов страницы.
- **Clear** — очистить поля и результаты **только текущей расчётной вкладки**.
  Остальные вкладки и общие настройки сохраняются. На History & Saves кнопка
  Clear недоступна.
- **Close** — скрыть калькулятор, сохранив введённые данные.

Поля, результаты, история и выбранная вкладка сохраняются между запусками игры.
Разворачивание и скрытие окна тоже сохраняют данные.

### Основные поля

| Название | Что означает |
| --- | --- |
| **Budget** | Бюджет на комплектующие. Оплату за работу сюда не добавляйте. |
| **Reserved Budget** | Деньги, отложенные на детали, которые вы будете подбирать отдельно: БП, охлаждение, накопители и другие покупки. |
| **Target Score** | Требуемый результат 3DMark из задания. |
| **Score Offset** | Насколько выше цели разрешено искать варианты. |
| **# Results** | Сколько вариантов запрашивать. |
| **Case** | Корпус. |
| **M.2** | Установленный накопитель M.2, если он есть. |
| **Motherboard** | Материнская плата. |
| **RAM Speed / RAM Sticks** | Частота ОЗУ / количество установленных модулей. |
| **# GPUs** | Количество видеокарт. |
| **GPU Type: Air / Water** | Воздушное / водяное охлаждение видеокарты. |
| **CPU Brand / GPU Vendor / Brand** | Ограничение по марке процессора или видеокарты. |
| **Required …** | Конкретная обязательная модель детали. Пустое поле означает свободный выбор. |
| **Any** | Подойдёт любой вариант. |

**Career Level** и **% Through** — ваш уровень и целый процент опыта.
Они заполняются из игры автоматически.

Галочка **All Parts Unlocked?** разрешает калькулятору учитывать все детали.
Используйте её, если детали уже открыты модом или читом. Для обычной карьеры
с ограничениями оставьте её выключенной. В Esports DLC, IT Expansion и свободной
сборке ограничение по карьерному уровню не применяется.

### Самый удобный способ: кнопка «Помощник» в письме

1. Откройте письмо с заданием на результат **3DMark**.
2. Рядом с действием заказа нажмите **«Помощник»** — при английском языке игры
   кнопка называется **Helper**.
3. Для новой сборки откроется **Build Maker**, для существующего ПК —
   **Build Upgrader**. Бюджет, цель и доступные характеристики перенесутся сами.
4. Раскройте **«Условия задания и ограничения расчёта»** и проверьте данные.
5. Нажмите **Get Builds** или **Get Upgrades**, чтобы получить варианты.
6. Выберите подходящий вариант, купите и установите детали в игре.

Например, если в письме указан бюджет **$540**, оплата работы **$140** и цель
**4800**, помощник заполнит **Budget = 540**, **Target Score = 4800**.

Нажатие «Помощник» **не принимает заказ и не запускает расчёт**.
Перенос заменяет данные только в нужной вкладке; остальные вкладки остаются.
Условия по марке, двум GPU, водяным GPU и поддерживаемым обязательным моделям
учитываются при подборе.

Для новой сборки **Reserved Budget** сначала равен **400**. Измените резерв
под свои покупки. БП, накопители, ремонт, полное охлаждение и точные частоты
разгона нужно подбирать и проверять отдельно. Если в ПК несколько M.2 или
две разные модели GPU, проверьте замечания в блоке условий.

## F3 — Will it Run? Helper

Эта панель нужна для заданий **«Можно поиграть в …»**. Она показывает требования
игры без поиска в длинном списке приложения Will it Run?.

1. Откройте письмо с таким заказом или посмотрите на клиентский ПК с заданием.
2. Справа появится панель с названием игры и профилем требований:
   минимальные, рекомендуемые или 4K.
3. В ней будут нужные ОЗУ, видеопамять, GPU, CPU и место на диске.
4. Нажмите **F3**, чтобы закрепить панель и оставить её видимой при поиске
   деталей в магазине. Повторное F3 скрывает её.

**«Выбрать игру»** позволяет найти игру вручную. **«Из задания»** возвращает
требования текущего заказа. Для нажатия кнопок удерживайте **Alt**.

Рядом с CPU указан **сокет** — разъём процессора. Ниже показывается один
самый дешёвый доступный подходящий CPU другой марки: Intel вместо AMD
или AMD вместо Intel. Сокет процессора и материнской платы должен подходить.
Если доступного аналога нет, панель сообщит об этом.

## Как обновить или удалить

**Обновление:** закройте игру, замените `PCBSCalculator.dll` в той же папке
новой версией и запустите игру снова. Не оставляйте вторую копию DLL в другом
месте внутри plugins. BepInEx заново устанавливать не нужно, если версия 5
уже работает. Отдельные HTML/JS/CSS от старой установки новой DLL не нужны.

**Удаление:** при закрытой игре перенесите папку
`BepInEx/plugins/PCBSCalculator` за пределы plugins. BepInEx можно оставить
для остальных модов.

Настройки и данные хелпера находятся в папке игры:

- `BepInEx/config/local.pcbs.calculator.cfg` — переключатели, клавиши и позиции окон.
- `BepInEx/config/PCBSHelper/calculator-state.json` — данные калькулятора.

При обычном обновлении их менять или удалять не нужно.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Ни одно окно не открывается. | Зайдите в мастерскую; проверьте путь к DLL, BepInEx 5 x64 и попробуйте Fn + F1/F2/F3. |
| F1 работает, а F2 или F3 — нет. | Откройте F1 и включите **Calculator** / **Will it Run Helper**. |
| Не получается нажать кнопку в маленьком окне. | Удерживайте **Alt**, чтобы получить курсор. |
| Нет кнопки «Помощник». | Она появляется у выбранного письма с целью 3DMark, когда включён Calculator. |
| Панель F3 не появилась сама. | Проверьте, что в задании есть цель «Можно поиграть». Можно открыть панель через F3 и выбрать игру вручную. |
| Нет подходящих сборок или апгрейдов. | Проверьте бюджет, резерв, уровень и ограничения деталей. При необходимости увеличьте Score Offset или # Results. |
| Окно оказалось в неудобном месте. | Перетащите заголовок. Для сброса при закрытой игре замените нужное значение **CalculatorPosition**, **TweakerPosition** или **RequirementsPosition** в разделе `[Layout]` конфига на `default`. |
| На F1 открывается ещё и старое меню. | Перенесите отдельный CheatMod.dll за пределы BepInEx/plugins. |
| F2 мешает открывать игровой BIOS. | При закрытой игре откройте конфиг Блокнотом. В `[Controls]` измените **ToggleKey = F2**, например на **ToggleKey = F4**, сохраните и перезапустите игру. |

Для сообщения об ошибке приложите **BepInEx/LogOutput.log**, версию игры,
версию хелпера и короткое описание действий. Если LogOutput.log вообще
не появился после запуска, сначала проверьте установку BepInEx.
