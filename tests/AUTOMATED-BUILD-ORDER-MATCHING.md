# Сопоставление деталей и частичный заказ

9 октября 2026 года, PCBS-Helper 1.2.3.

Исправлен реальный отказ для AMD Ryzen 7 Eight Core 1700: таблица игры содержит
`CPU_AMD_6` и служебную строку `DUMMY Ryzen 7 Eight Core 1700` с одинаковым
именем. Прежний поиск отвергал такое совпадение как неоднозначное. Теперь
строки DUMMY и детали вне магазина исключены из кандидатов. Для некоторых
MSI RTX исходный HTML калькулятора содержит знак ™ в старой кодировке;
при загрузке он становится `�`. Эти незначимые символы нормализуются.

`CompareGameCatalog.py` прочитал таблицы CPU, GPU, Water Cooled GPU, Cases,
RAM и Motherboard из локальной игры 1.15.3 и сопоставил **126 CPU + 316 GPU +
337 корпусов + 340 моделей ОЗУ + 145 плат**, без конфликтов, с игровыми ID.
Учитываются обычные модели в магазине; HEM-детали исключены
из сравнения с немодифицированной игрой. Частные таблицы и фикстуры остаются
в исключённом из Git `build/`.

`Build.ps1 -Test` с локальной фикстурой: **2046 утверждений прошли**,
включая проверку всех 1264 моделей кодом хелпера. Дополнительно проверены
порядок DUMMY/реальной строки, повреждённые символы, точные количества
Ryzen/EVGA GPU и частичный заказ при отсутствующем корпусе/закрытой RAM.
API `AddBatch` сохраняет проверку целиком внутри одной позиции с количеством;
заказ сборки теперь обрабатывает позиции независимо.

При проверке корпусов обнаружены ещё два повреждённых названия:
Fractal Design Meshify C – TG и Meshify C – Dark TG. Декоративное тире,
окружённое пробелами, нормализуется; обычные дефисы в номерах моделей
сохраняются. Отдельные тесты проверяют, что TG, Dark TG и обычный Meshify C
получают свои ID. ОЗУ сравнивается с `Size each (GB)` и `Frequency`, как
эти поля читает `PartDescRAM.ImportProp`; объём, частота и цветовая версия
не заменяются похожими вариантами.

Браузер: 15 проверок частичного заказа, прежние 24 + 5 проверок заказа и
восстановления, 18 + 6 проверок локализации/истории — все 68 прошли.
Проверены количество принятых деталей, полный список пропущенных моделей,
причины отказа, переключение языка предупреждений и отсутствие повторного
добавления при щелчке по частично подтверждённому результату.
Проверка предупреждений в браузере использует имитацию ответа игры.
В настоящей игре подтверждены наличие открытой таблицы и сообщение об отказе
на старой DLL; новый код требует перезапуска игры перед проверкой корзины.
Данные сохранения и покупки при диагностике не изменялись.

После обновления проверить выбранную строку со скриншота: CPU должен
добавиться как `CPU_AMD_6`, две EVGA GTX 1080 GAMING — как две единицы
`GPU_EVGA_4`. Неизвестная/недоступная RAM или корпус не должны блокировать
CPU/GPU; для каждой пропущенной позиции выводится имя, количество и причина.
