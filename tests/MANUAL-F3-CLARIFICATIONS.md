# Уточнения заказа в F3

11 октября 2026 года. Пользователь снял F3 с итогового PASS: в заказе №528
на Adobe Premiere Pro CC (rec) с i5-6400 и GTX 970 условие «Установить
комплектующие AMD» показывалось без аналога. Причина — неоднозначный общий
бренд: AMD выпускает CPU и GPU; такая цель прежде отображалась только текстом.

Исправленная локальная 1.0.1 предлагает CPU/GPU-варианты и для общего бренда.
Для AMD/Intel предпочтение отдаётся процессору; явная GPU-цель сохраняет
подбор карты. Проверен также общий EVGA, выпускающий GPU и БП. При двух
вариантах для общего бренда панель уточняет, что достаточно одной новой
детали; для количества >1 требуется ручной подбор сочетания.

Автоматические проверки: 60 утверждений планировщика уточнений,
28 проверок чтения реальных классов целей PCBS 1.15.3 и 17 проверок
локализации. Весь `Build.ps1 -Test` прошёл. Игровой PASS для исправленной F3
остаётся неподтверждённым до повторной проверки пользователя.

После установки подготовленной сборки проверить:

1. Заказ только с Will it Run?: основной профиль показан, «Уточнения заказа»
   и постоянного «Аналога CPU» нет. Бренд, уже совпадающий с эталоном, не
   дублируется; тот же результат при ручном выборе игры без заказа.
2. Эталон CPU AMD и пожелание Intel: показано условие Intel и подходящий
   открытый CPU с сокетом/ценой. CPU слабее эталона или закрытый по уровню
   не предлагается. Повторить в обратную сторону с общим условием AMD:
   заказ №528 должен показать конкретный аналог CPU с сокетом и ценой.
   При доступном CPU общее AMD не предлагает менять GPU одновременно.
3. Эталон AMD Radeon и пожелание NVIDIA: показано ограничение GPU и карта
   с достаточной производительностью и VRAM. Карта EVGA на чипе NVIDIA
   не заменяет производителя NVIDIA, если цель требует именно производителя.
   Повторить с конкретной моделью AMD Vega и общим условием EVGA: оба пути
   должны предлагать GPU достаточной производительности и объёма VRAM.
4. Память Team Group, HDD Seagate, новый комплект или цвет кабелей: уточнения
   видны без ненужного предложения CPU. Общее «использовать Team Group» не
   превращается в условие только на ОЗУ. Скрытое пожелание письма остаётся
   в уточнениях при выключенном показе скрытых целей в F1.
5. RAM/Storage больше профиля: показано дополнительное условие. Равное или
   меньшее значение не добавляет повторную строку.
6. DLC конкретная модель/бренд категории/запрет бренда/количество: точный
   ID и количество сохраняются. Несовместимые одновременные условия дают
   отсутствие подходящей замены, а не частично подходящую модель.
7. Ограничение CPU/GPU вместе с разгоном, водоблоком, апгрейдом, отдельной
   целью 3DMark или двумя GPU:
   уточнения сохранены, вместо неполного подбора предлагается ручной выбор.
8. Два заказа для одной игры с разными пожеланиями: переключение письма
   обновляет условия. Закреплённая панель не подменяет свой заказ чужими
   условиями. «Выбрать игру» убирает уточнения; «Из задания» возвращает их.
9. Несколько игровых целей: «Следующая цель задания» пересчитывает отличия
   относительно выбранного профиля. RU/EN меняет заголовки и текст целей.
10. Длинный список уточнений, 1280×720 и 1920×1080: прокрутка работает,
    строки переносятся, нижняя подсказка Alt остаётся вне прокручиваемого списка.
