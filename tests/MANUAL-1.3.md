# Ручная проверка PCBS Helper 1.3

Сборка и автоматические тесты: 13 проверок CPU matcher и 12 проверок расчёта/
сериализации позиции окон прошли. Игровые проверки выполняет пользователь.

- [ ] **Перемещение:** открой F1, компактный F2 и F3. Перетащи каждое окно за
  заголовок в отдельное место. В режиме управления персонажем используй Alt.
  Поля, переключатели и кнопки после перемещения должны работать; персонаж и
  камера не должны двигаться вслед за перетаскиванием.
- [ ] **Внутри сессии:** скрой и снова открой каждое окно. Позиция должна остаться
  той же. Панель F3 должна сохранять место при закрытии/открытии задания.
- [ ] **Размер F2:** введи тестовые данные/получи результат, нажми Expand, затем
  Compact. Компактное окно должно вернуться на выбранное место, данные сохраняются.
- [ ] **Перезапуск:** перетащи окна, отпусти мышь, закрой игру обычным способом и
  запусти снова. У каждого окна должно сохраниться своё положение.
- [ ] **Функции в Tweaker:** выключи Calculator — F2 больше не открывает хелпер.
  Выключи Will it Run Helper — F3 и автопоказ требований отключены. После перезапуска
  они должны остаться выключенными; повторное включение возвращает их работу.
- [ ] **Границы экрана:** попробуй увести окно за край экрана. Заголовок должен
  оставаться доступным. При смене разрешения окна должны оставаться на экране.
- [ ] **Перекрытие:** размести F2 или Tweaker поверх F3. Нажатия и перетаскивание
  должны обрабатываться передним окном, без кликов по панели под ним.

Для сброса позиции при закрытой игре: общий конфиг → `[Layout]` → нужное
`...Position = default`. Эти действия не меняют игровые сохранения.
