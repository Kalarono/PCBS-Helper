# Ручная проверка PCBS Helper 1.4.1

Предыдущая версия 1.4 прошла игровую проверку пользователя: сохранение и Clear,
синхронизация опыта, аналоги CPU и прочие функции работают. Остались две правки.

1. **Целый процент опыта.** В обычной карьере открыть F2: % Through отображается
   целым числом (например, 25 вместо 25.1234), без округления вверх.
   Получить опыт: число обновляется автоматически. All Parts Unlocked?
   сохраняет выбранное состояние.
2. **F3 → F1 → закрыть F1.** Закрепить панель F3, открыть F1 и закрыть его
   через F1, Esc или кнопку. Панель F3 не возвращается.
3. **F3 → F2 → закрыть F2.** Повторить для F2, включая Expand и Compact.
   Панель F3 не возвращается.
4. **Автоматическая панель.** Открыть задание с целью «Можно поиграть»,
   перейти в F1/F2 и закрыть его. Требования не возвращаются поверх того же
   открытого задания. F3 снова открывает их, повторное F3 скрывает.
   Закрытие и новое открытие задания снова разрешает автопоказ.
5. **Обратное переключение.** F1/F2 → F3 → закрыть F3: другие окна не
   возвращаются. Выбранная игра, поля F2 и позиции панелей сохраняются.
