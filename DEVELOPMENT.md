# Для разработчиков PCBS-Helper

Инструкция для игроков находится в [README.md](README.md). Этот файл описывает сборку из исходников, проверки и подготовку пакета.

## Сборка

Нужны Windows, установленная игра и BepInEx 5. Используется C# compiler .NET
Framework из Windows. DLL игры берутся **только из локальной установки**.
Для сборки нужен `assets/calculator.html`. Если файла нет, добавьте
`-FetchCalculator`: скрипт загрузит его с исходной страницы автора.
HTML, CSS и JavaScript встраиваются в DLL как ресурсы; для установки мода
достаточно BepInEx 5 и `PCBS-Helper.dll`.

```powershell
.\Build.ps1 -GamePath 'D:\SteamLibrary\steamapps\common\PC Building Simulator' -Test
# Закройте игру, затем установите мод:
.\Build.ps1 -GamePath 'D:\SteamLibrary\steamapps\common\PC Building Simulator' -Install -Test
```

Можно задать `PCBS_GAME_PATH` или локальный, исключённый из Git `build.local.json`:

```json
{ "gamePath": "D:\\SteamLibrary\\steamapps\\common\\PC Building Simulator" }
```

Пакет: `build/package/PCBS-Helper/`. Файл `PCBS-Helper.dll` сам содержит
все файлы калькулятора. Скопируйте его в `BepInEx/plugins/PCBS-Helper/`.
Скрипт `Build.ps1 -Install` сохраняет заменяемые файлы в `build/backups/`
и не меняет игровые DLL или сохранения. Для удаления хелпера перенесите папку
PCBS-Helper за пределы plugins.

## Калькулятор и публикация исходников

Оригинальный калькулятор: **Jacob W. Klein**, [исходная страница](https://jacobwklein.github.io/PC-Building-Simulator/HTML-Calculator/Current-Version/PC-Building-Simulator-HTML-Calculator.html).

`assets/calculator.html` — неизменённая локальная копия; она исключена из Git.
Загрузить её отдельно можно через `scripts/Fetch-Calculator.ps1` или
`Build.ps1 -FetchCalculator`. `embedded-ui.js` добавляет отображаемые внутри
игры select/datalist-меню. `calculator-theme.css` адаптирует страницу к компактной
тёмной панели; формулы и база исходного калькулятора не изменяются.
`calculator-state-codec.js` и `calculator-state.js` добавляют сохранение,
Clear и синхронизацию уровня. Обёртка расчёта 3DMark сохраняет использование
полной базы деталей, как предусмотрено исходным калькулятором, даже когда
для подбора сборок включён фильтр уровня.
`calculator-job-import.js` и `calculator-job-rules.js` добавляют перенос заказа
и дополнительные ограничения результатов; исходный HTML остаётся неизменённым.
Общие ограничения по количеству деталей определённого производителя для Maker
проверяются после подбора: число показанных вариантов может быть меньше # Results.
При необходимости увеличьте это число. Для Upgrader фильтр применяется до
сокращения набора результатов.
В Upgrader общие условия по марке применяются к поиску, если производитель
есть среди CPU, GPU или плат в полной базе. Условия по остальным маркам
(например, HyperX для RAM) сохраняются в заказе с пояснением о проверке
в игре и не отбрасывают варианты замены CPU/GPU/платы. Maker продолжает
учитывать марки всех подбираемых деталей, включая корпус и RAM.
`calculator-localization.js` переводит только отображение; исходный HTML
не меняется. Значения select, модели деталей, комментарии и сохранённые
данные остаются каноническими. Охлаждение в таблицах отображается через CSS,
чтобы исходное сохранение сборок продолжало получать `Air` / `Water`.
`HelperLocalization.cs` читает язык игры для нативных панелей; браузер
синхронизирует его через `pcbsSetLanguage` без перезагрузки страницы.
`PanelCursorMode` хранит переключение Alt для F2/F3 и сбрасывает его при
смене панели или потере фокуса. Освобождение курсора также возвращает
игровой ввод; Alt не отправляется в поля встроенного браузера.
Адаптер состояния задаёт 10 результатов для пустого поля и после Clear,
но сохраняет явно введённое число. Поля `pcbsFixed*` находятся в скрытых
строках формы: сохраняются и ограничивают поиск через импорт заказа.
Текст требований самого задания приходит из игры на языке переноса.
Сборка проверяет наличие всех восьми ресурсов и останавливается, если какой-то
отсутствует. При чтении встроенные ресурсы имеют приоритет над внешними файлами
от старых установок, поэтому оставшиеся HTML/JS/CSS не подменяют новую версию.

Исходники не включают DLL, базы игры или сохранения. Перед публичным релизом
выберите лицензию проекта и отдельно проверьте право включать чужой калькулятор
в распространяемый пакет. В этом репозитории чужой HTML не публикуется.

## Проверки

`Build.ps1 -Test` проверяет подбор Intel ↔ AMD, точное равенство порогу, запрет
более слабых CPU, сортировку, дубликаты, некорректные оценки и фильтр доступности. Для проверки
интеграции нужны запуск игры, выбранный ПК/письмо с CanPlay-целью и сравнение
полей панели с Will it Run? для того же профиля.

Результаты ручной проверки: [tests/INTEGRATION.md](tests/INTEGRATION.md).
Тесты позиции окон дополнительно проверяют сериализацию, восстановление на том
же разрешении, перенос на другое разрешение, ограничение экраном и повреждённые значения.
Тесты также проверяют вычисление уровня/процента опыта и независимое сохранение
и очистку вкладок калькулятора. Изолированная браузерная проверка проверяет
настоящий расчёт 3DMark, Clear и восстановление страницы после перезагрузки;
она не заменяет проверку встроенного браузера в игре.
Сохранение и очистка калькулятора: [tests/MANUAL-1.4.md](tests/MANUAL-1.4.md).
Процент опыта и переключение окон: [tests/MANUAL-1.4.1.md](tests/MANUAL-1.4.1.md).
Проверка кнопки и переноса заказа: [tests/MANUAL-1.5.md](tests/MANUAL-1.5.md).
Проверка расположения кнопки: [tests/MANUAL-1.5.1.md](tests/MANUAL-1.5.1.md).
Номера в названиях этих файлов — прежние внутренние обозначения промежуточных
сборок; публичная история версий приведена в CHANGELOG.md.
