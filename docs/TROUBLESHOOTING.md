# Решение проблем PCBS-Helper

Установка: [README.md](../README.md). Управление: [USAGE.md](USAGE.md).

Настройки и данные находятся в папке игры:

- `BepInEx/config/local.pcbs.calculator.cfg` — переключатели, клавиши и позиции окон.
- `BepInEx/config/PCBSHelper/calculator-state.json` — данные калькулятора.

При обычном обновлении их менять или удалять не нужно.

| Проблема | Что проверить |
| --- | --- |
| Ни одно окно не открывается. | Зайдите в мастерскую; проверьте путь к DLL, BepInEx 5 x64 и попробуйте Fn + F1/F2/F3. |
| F1 работает, а F2 или F3 — нет. | Откройте F1 и включите **Помощник по сборке** / **Помощник Will it Run?**. |
| Не получается нажать кнопку в окне. | Нажмите **Alt**, чтобы включить курсор. |
| Нет кнопки «Помощник». | Она появляется у выбранного письма с целью 3DMark, когда включён «Помощник по сборке». |
| Панель F3 не появилась сама. | Проверьте, что в задании есть цель «Можно поиграть». Можно открыть панель через F3 и выбрать игру вручную. |
| Нет подходящих сборок или апгрейдов. | Проверьте бюджет, резерв, уровень и ограничения деталей. При необходимости увеличьте Score Offset или # Results. |
| Окно оказалось в неудобном месте. | Перетащите заголовок. Для сброса при закрытой игре замените нужное значение **CalculatorPosition**, **TweakerPosition** или **RequirementsPosition** в разделе `[Layout]` конфига на `default`. |
| F2 мешает открывать игровой BIOS. | При закрытой игре откройте конфиг Блокнотом. В `[Controls]` измените **ToggleKey = F2**, например на **ToggleKey = F4**, сохраните и перезапустите игру. |

Для сообщения об ошибке приложите **BepInEx/LogOutput.log**, версию игры,
версию хелпера и короткое описание действий. Если LogOutput.log вообще
не появился после запуска, сначала проверьте установку BepInEx.
